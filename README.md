# TBox

Калькулятор закрытого корпуса сабвуфера: идеальная АЧХ, fc/Qtc/f3, размеры полости и наружные размеры с учётом вытеснения оборудования. Основной динамик — EDGE EDS15D1-E7 владельца; JL Audio 12W0v3-4 доступен дополнительным пресетом. Восстановлены 2D/3D, фазоинвертор, меню и всплывающие подсказки.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test --run
pnpm lint
pnpm build
```

`pnpm test` запускает режим наблюдения. Для однократного запуска используйте `--run`.

[Аудит расчётов, источники и ограничения модели](docs/calculation-audit.md).

Рабочие константы: `src/core/constants.ts`; источник примера: `src/data/drivers.ts`. В расчётах Fs/fc/f3 — Гц, Vas/Vb — литры, Sd — см², Xmax — мм; в геометрии стороны — см, толщины материала — мм.

TypeScript 7 используется для сборки; совместимый TypeScript 6 API подключён отдельно для ESLint официальным npm alias.

Проверка интерфейса через встроенный браузер Orca (при работающем dev-сервере):

```sh
python3 scripts/browser-smoke.py http://127.0.0.1:5174/
```

[Запись восстановления интерфейса и актуальные ограничения](docs/interface-restoration.md).

Правила для всех текущих и будущих графиков: [поведение АЧХ](docs/chart-behavior.md).

## Проверка перед деплоем

```sh
pnpm check
pnpm preview --host 0.0.0.0 --port 5175 --strictPort
# В другом терминале при работающей Orca:
python3 scripts/browser-smoke.py http://localhost:5175/
```

`pnpm check` выполняет тесты, lint и production-сборку. Для статического хостинга публикуется содержимое `dist/`; команда сборки — `pnpm build`, каталог результата — `dist`. Текущая конфигурация рассчитана на корень домена. `vite preview` предназначен для локальной проверки собранных файлов.

Обязательные сценарии ЗЯ включают ручные размеры, 2D/3D, чертёж и вырез, монтажные конфликты, неизвестные данные, вытеснение без оставшегося объёма, поправку салона и ширины экрана 320/390 px. Происхождение данных EDGE и ограничения изготовления описаны в [отчёте по плану](docs/plans/2026-11-12-sealed-box-production-progress.md). Проверка сборки не заменяет проверку конкретного корпуса перед изготовлением.

## Простой и экспертный режимы ЗЯ

Первое открытие ЗЯ использует простой режим. Он показывает пресет, целевой чистый объём, условия расчёта, основные метрики и график. Экспертный режим раскрывает T/S, монтаж, вытеснение, материал и ограничения, ручные размеры, 2D/3D/чертёж и параметры условной поправки салона. Оба используют одно расчётное ядро.

Настройки сохраняются только в текущем браузере (`tbox.sealed-draft.v1`). Переключение режима и перезагрузка сохраняют введённые значения, включая незаполненные поля. «Новый расчёт» возвращает исходные настройки; до перезагрузки это действие можно отменить. При недоступном хранилище расчёт продолжает работать, но интерфейс предупреждает, что черновик не будет восстановлен после перезагрузки.

Начальные запасы компоновки — 30 мм от рамы до края панели и 20 мм за динамиком; они редактируются и не выдаются за требования производителя. Неизвестное вытеснение EDGE не подменяется типовыми 3–5 л. Баланс объёма отдельно показывает цель, полость, вычеты и расчётный чистый Vb.

Дополнительная проверка режимов и черновика на собранной версии:

```sh
python3 scripts/sealed-modes-smoke.py http://localhost:5175/
```

Оба браузерных сценария используют отдельные тестовые профили и не меняют сохранённый черновик владельца. Запускайте их последовательно: переключение вкладки Orca может инвалидировать ссылки на элементы другого выполняющегося сценария.
